🧠 Deep Agent Memory (AGENTS.md)

Đây là "bộ nhớ dài hạn" của Agent. Nó sẽ đọc file này trước khi phân tích để ghi nhớ các xu hướng và yêu cầu đặc biệt của bác. Bác có thể chỉnh sửa trực tiếp bên dưới.

🤖 Cách hoạt động của Deep Agent
• Autonomous: Agent tự quyết định khi nào cần đọc bài cũ, khi nào cần update bộ nhớ.
• General Purpose: Không bị giới hạn chủ đề (Bất động sản, IT, Tin tức...).
• Local First: Chạy hoàn toàn trên máy bác, dữ liệu lưu vào SQLite và file Markdown.

📖 Hướng Dẫn Cài Đặt
① Cài đặt môi trường Python
python -m venv venv source venv/bin/activate # Windows: venv\Scripts\activate pip install -r requirements.txt
② Cài Google Chrome & ChromeDriver
# Cài Chrome (Ubuntu) wget -q -O - https://dl.google.com/linux/linux_signing_key.pub | sudo apt-key add - sudo apt install google-chrome-stable # ChromeDriver tự động (webdriver-manager) # Đã được tích hợp sẵn trong requirements.txt
③ Lấy Cookie Facebook
1. Đăng nhập Facebook trên Chrome
2. Mở DevTools (F12) → Application → Storage → Cookies → facebook.com
3. Copy tất cả cookies dưới dạng: c_user=xxx; xs=xxx; datr=xxx;
4. Dán vào ô Cookie trong tab Cấu hình
④ Tạo Google Service Account
1. Vào Google Cloud Console → IAM & Admin → Service Accounts
2. Tạo tài khoản mới → Generate JSON key
3. Chia sẻ Spreadsheet với email của service account
4. Dán JSON vào ô Credentials
⑤ Khởi động hệ thống
python main.py # Truy cập: http://localhost:5000 # Hoặc dùng Docker Compose docker compose up -d
