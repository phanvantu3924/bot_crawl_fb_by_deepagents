🧠 Deep Agent Memory (AGENTS.md)

Bộ nhớ dài hạn của Agent Orchestrator. Ghi hướng dẫn và xu hướng quan sát được để agent đọc trước khi chạy.

🤖 Sub-Agents
🔍 Analyzer sub-agent — Phân tích từng bài viết, gán nhãn mức độ (cao / trung_bình / thấp / không liên quan), khớp chủ đề theo dõi. Có 3-tier fallback: structured output → JSON parse → keyword match.
📝 Reporter sub-agent — Tạo báo cáo theo format chuẩn: tổng bài, khung giờ, danh sách liên quan, danh sách đầy đủ. Xuất Markdown file + Telegram HTML.
🧠 Orchestrator — DeepAgent điều phối pipeline, gọi sub-agents, lưu memory, gửi Telegram.

📖 Hướng dẫn cài đặt
① Cài đặt môi trường
python -m venv venv source venv/bin/activate # Windows: venv\Scripts\activate pip install -r requirements.txt
② Chạy server
python main.py # Hoặc Docker: docker compose up -d
③ Cấu hình Pages
Vào tab Cấu hình Pages → Thêm URL Facebook Page/Group → Gán chủ đề theo dõi cho từng page → Lưu cấu hình.
④ Lấy Cookie Facebook
Chrome → Đăng nhập FB → F12 → Application → Cookies → facebook.com → Copy tất cả dưới dạng key=value; key2=value2
⑤ Workflow tự động
# Mỗi ngày theo lịch cron: # 1. Scraper: thu thập bài từ các Pages → data/raw/YYYY-MM-DD.json # 2. Analyzer sub-agent: phân loại mức độ liên quan # 3. Reporter sub-agent: tạo báo cáo → data/reports/YYYY-MM-DD.md # 4. Gửi báo cáo qua Telegram
